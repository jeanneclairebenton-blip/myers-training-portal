# Myers Post Standards — UNIFIED (v2, final)

**One library:** every post lives in `Social Media Content/All-Sizes/<Post-Name>/` as a folder of four labeled files plus a READ-ME:

| File | Platform | Dimensions |
|---|---|---|
| `<Name> - Facebook (1080x1350).png` | Facebook feed | 1080×1350 (4:5) |
| `<Name> - Instagram (1080x1350).png` | Instagram feed | 1080×1350 (4:5) |
| `<Name> - LinkedIn (1080x1350).png` | LinkedIn feed | 1080×1350 (4:5) |
| `<Name> - Story (1080x1920).png` | IG/FB Story · Reels | 1080×1920 (9:16) |

4:5 is the shared feed standard all three platforms render at full size; Story is its own 9:16 layout — not a stretched copy.

**Type floor:** nothing below ~28px on the 1080 canvas (≈14pt). If it doesn't fit at 28, the layout changes, not the type. (The flyer generators now enforce this floor internally.)

**Design rules:** one focal point, one CTA, high contrast, generous margins, Title Case on graphics, Myers chrome (logo + gold kicker + rule + brand footer), Inter only, gold confetti on celebrations only.
